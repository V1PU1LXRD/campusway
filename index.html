      Route Summary

      CampusWay · Graphs, Min-Heap, Dijkstra, BFS & A* · built with vanilla JavaScript —

      About the algorithms

      Dijkstra's algorithm — “reliable shortest route”

      Expands outward from the start, always settling the closest unsettled building first. Because every walkway has a positive length, the first time Dijkstra reaches a building it has found the shortest walk there. Best when: you need the guaranteed shortest distance on a weighted graph.

      Breadth-First Search — “fewest buildings passed”

      Explores level by level with a plain first-in-first-out queue, ignoring walkway lengths. It finds the route through the fewest edges, which is a different goal — that route can be longer in metres.

      A* search — “goal-directed Dijkstra”

      Dijkstra plus a heuristic: straight-line distance to the destination. The estimate never overestimates the true remaining walk, so A* keeps Dijkstra's guarantee while usually exploring fewer buildings. Note: A* is only as efficient as its heuristic — a poor one collapses it back toward plain Dijkstra.

      Data structures used

      • Adjacency list — the campus graph (Map<building, walkways[]>)
      • Binary min-heap — priority queue for Dijkstra and A* (written from scratch)
      • FIFO queue — BFS frontier
      • Visited/settled set & parent map — route reconstruction

      Complexity summary

      • Dijkstra: O((V+E) log V) with the min-heap
      • BFS: O(V + E)
      • A*: O((V+E) log V), fewer expansions with an admissible heuristic
